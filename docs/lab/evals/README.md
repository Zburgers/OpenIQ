# Evals — sealed employee files (employees never read)

Contains secret HR/board evaluations. Structure:

- `tracker.md` — cycle rankings (output quality, proactivity, collaboration, tokens/tools proxies).
- `<slug>.md` — one case file per employee per cycle (evidence table + scores + recommendation).
- `members/archive/` (sibling) — fired instances' sealed notes; never restarted; never shown to new hires.

Do not surface contents to scientists. CEO relays outcomes only as staffing changes.
