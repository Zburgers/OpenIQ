# I — Computerized Adaptive Testing (CAT)

Study item selection criteria, theta initialization, EAP/MAP/MLE updates, stopping rules, target SE, content balancing, exposure control, item-bank security, shadow testing, simulations, and equivalence with fixed forms.

## OpenIQ sequencing rule

CAT is **not v0.1**. First reproduce fixed-form scoring. Then simulate CAT offline with calibrated items and quantify bias/RMSE/coverage/test length across theta before administering adaptively to real participants.
