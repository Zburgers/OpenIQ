# B — Classical Test Theory

Study `X = T + E`, reliability vs validity, standard error of measurement, internal consistency, omega/alpha, split-half reliability, test–retest reliability, parallel forms, ceiling/floor effects, and score precision.

## OpenIQ decisions to research

- prefer reliability coefficients appropriate to dimensionality; do not treat Cronbach's alpha as universal proof;
- report measurement error/intervals rather than exact-looking point scores;
- separate practice/retest effects from reliability;
- use CTT as complementary evidence even when IRT is the primary scoring framework.

## First exercise

Reproduce reliability estimates from an open dataset and show how different reliability values alter the standard error on an SD=15 reporting scale.
