# K — Online Testing, Hardware, and Environment

A browser measures **person + task + device + environment**. For untimed reasoning, hardware may have modest impact; for reaction-time/processing-speed tasks, display/input/browser latency can materially contaminate milliseconds.

Study browser timing APIs, monitor refresh, touchscreen vs keyboard/mouse, OS/device latency, screen size, mobile vs desktop, distraction, interruptions, unproctored testing, cheating/help-seeking, focus changes, repeat exposure, accessibility, and practice effects.

## OpenIQ policy direction

- record device/browser/OS/viewport/input method for every session;
- record focus/visibility changes as quality metadata, not automatic proof of cheating;
- define supported hardware per speeded task;
- do not compare raw millisecond scores across devices unless evidence supports it;
- preserve an untimed reasoning pathway where hardware latency is less central.
