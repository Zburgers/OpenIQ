# G — Validity

Treat validity as an evidence-based argument for a **specific score interpretation/use**, not a permanent badge attached to a test.

Study evidence based on test content, response processes, internal structure, relationships with external variables, and consequences/use. Distinguish convergent, discriminant, criterion/predictive evidence and incremental validity where relevant.

## OpenIQ claims ladder

1. software computes responses correctly;
2. replicated psychometric scoring works;
3. score estimates the intended narrow construct in a named reference population;
4. multidomain structure supports broader interpretation;
5. norms/generalization support population-relative interpretation;
6. high-stakes/clinical use would require substantially stronger evidence and governance.
