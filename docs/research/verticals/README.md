# OpenIQ Research Verticals

These verticals form the study curriculum. Each has a different failure mode; skipping one can produce a technically polished but scientifically invalid test.

| ID | Vertical | Core question |
|---|---|---|
| A | Theory of intelligence | What construct are we trying to measure? |
| B | Classical Test Theory | How consistent/precise are observed scores? |
| C | Item Response Theory | How do item properties and latent ability generate responses? |
| D | Factor analysis / latent structure | What dimensional structure does the battery actually support? |
| E | Norming / score scaling | Relative to which population does a standardized score mean anything? |
| F | Measurement invariance & DIF | Do items/scales behave comparably across groups? |
| G | Validity | What evidence supports the intended interpretation/use? |
| H | Fairness & cross-cultural assessment | What systematic barriers/biases distort interpretation? |
| I | Computerized Adaptive Testing | Can calibrated items achieve precision efficiently without breaking comparability/security? |
| J | Linking & equating | How can forms/item banks share a common metric? |
| K | Online testing / hardware | Does browser/device/environment alter what we observe? |
| L | Ethics, open science & research integrity | Can we collect/use/publish evidence responsibly and reproducibly? |

Every deep-research agent should finish with: definitions, canonical literature, disagreements/open questions, implications for OpenIQ, concrete decisions, experiments, and a bibliography.
